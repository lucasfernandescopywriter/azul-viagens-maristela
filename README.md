# Apresentação Comercial Executiva - Azul Viagens Matão

> **Proposta Comercial de Alta Conversão:** Sistema de Triagem, Qualificação e Atendimento Rápido (SDR Sofia) & Rastreamento com FunnelMax para Azul Viagens Matão (Maristela).

---

## 🚀 Como Executar

### 1. Visualização Direta no Navegador (Local)
Basta abrir o arquivo [`index.html`](index.html) ou [`apresentacao_pitch_executivo.html`](apresentacao_pitch_executivo.html) em qualquer navegador moderno (Google Chrome, Edge, Safari, Brave).

Nenhum servidor web, backend ou instalação de dependência é necessária. Todos os scripts, estilos e recursos são 100% autossuficientes e carregados via links relativos (`assets/`) ou fontes do Google Fonts CDN.

### 2. GitHub Pages (Online)
Ao habilitar o **GitHub Pages** na branch `main` (diretório raiz `/`), a apresentação fica disponível publicamente em:
```text
https://lucasfernandescopywriter.github.io/azul-viagens-maristela/
```

---

## ⌨️ Controles e Navegação

- **Teclado:**
  - `Seta para a Direita` (`→`) ou `Barra de Espaço`: Avançar slide
  - `Seta para a Esquerda` (`←`): Voltar slide
- **Mouse / Touch:**
  - Clique nos botões **Anterior** e **Próximo** na barra inferior (Dock estilo macOS).
- **Gate de Fechamento (Slide 12):**
  - O avanço para o Slide 13 (Apresentação de Valores e Fechamento) é travado intencionalmente até que os 3 critérios de alinhamento sejam marcados no Slide 12.

## 🛠️ Tecnologias Utilizadas
- **HTML5 semântico** com vídeos WebM codificados para alta performance.
- **CSS3 Moderno** com Glassmorphism, paleta oficial Azul Linhas Aéreas (`#002B49`, `#0082C9`, `#00C389`), tipografia Plus Jakarta Sans e JetBrains Mono.
- **SVG Dinâmico** para mapas mentais interativos e curvas de Bézier fluidas.
- **JavaScript Vanilla** (Zero dependências externas) para transição de slides e gatilhos de interação.
